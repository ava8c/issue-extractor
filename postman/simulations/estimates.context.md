# Issue estimates simulation

Run `postman simulation run postman/simulations/estimates.sim.yaml --port 4901 --output ndjson --no-history`.
Take member URLs from the `listening` event. Run `OPENAI_SIMULATION_URL=http://127.0.0.1:4901/openai GITHUB_SIMULATION_URL=http://127.0.0.1:4901/github npm test`.

The OpenAI fixture follows Models, Responses and Decisions JSON shapes documented at https://developers.openai.com/api/reference/resources/models/methods/list, https://developers.openai.com/api/docs/guides/structured-outputs and https://developers.openai.com/api/reference/resources/decisions/methods/create. It accepts only synthetic `simulation-*` keys. Its fixed Italian phrases model base estimates, additions, replacements and unquantified requirements. They do not measure a real model's interpretation quality. Test model IDs trigger 429, HTML 503, invalid JSON, invalid evidence, incomplete output, refusal and timeout paths. Decisions accepts only `gpt-6-luna`, returns named choices, confidence/probabilities and usage with zero output tokens; uncertain/refused choices trigger full reconstruction. Responses returns scalar `amount` values. The analysis/fix fixture deliberately emits a wrong amount to check the local explicit-total safeguard.

`POST /github/estimate-fixture` seeds synthetic issue text for the real GraphQL client. It exists only in the local mock. The tests use the real GitHub and OpenAI HTTP clients and the persisted estimate service. The default app always uses https://api.openai.com/v1; the simulation URL is injected by tests only.

No owning Postman workspace is linked to this repository; a published provider mock was not available locally. No resources are pushed or deployed. Local checks do not establish live model access, billing, interpretation quality, corporate proxy or Keychain behavior. Port binding may require sandbox permission on this Mac, as recorded in github.context.md.
